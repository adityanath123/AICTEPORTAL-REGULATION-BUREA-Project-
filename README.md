# AICTE Security Deposit / FDR Management Portal

## Live demo-link <a href="https://aicteportal-regulation-burea-projec.vercel.app/">Visit Website</a>

## Demo features

- Overview dashboard with portfolio metrics, charts, attention items, and recent activity
- Searchable and filterable FDR repository
- Add FDR form with client-side field validation and filename-only document selection
- Simulated verification review outcomes and discrepancy notes
- Renewal and release/refund request workflows
- Notifications, audit trail, and reports pages
- Demo role switcher; the Approving Authority role exposes simulated approval actions
- Responsive dark-navy sidebar and top navigation

## Important limitations

- The role switcher is for demonstrating UI flows and is not authentication or access control.
- Data changes exist only in browser memory and reset on refresh.
- Document upload only remembers the selected filename; no file is stored or transmitted.
- Verification results and approvals are simulated; there is no bank or AICTE system integration.
- All institution names, references, and financial data are illustrative sample data. Do not use real confidential records in this demo.
